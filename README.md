# PawaIT Weather App

The PawaIT Weather App is a full-stack application that displays current weather, a 3-day forecast, wind status, and humidity for a given city, with Nairobi as the default location. It consists of a Laravel backend and a Next.js frontend.

## Project Structure

## Features
- **Default Location**: Displays weather for Nairobi on page load.
- **Search**: Search for weather by city name.
- **Toggle Units**: Switch between Celsius and Fahrenheit.
- **Current Weather**: Shows weather icon, temperature, description, date, and city.
- **3-Day Forecast**: Displays forecast for the next three days.
- **Weather Details**: Shows wind status and humidity with progress bars.

## Tech Stack
- **Backend**: Laravel (PHP)
- **Frontend**: Next.js (TypeScript, Tailwind CSS)
- **API**: OpenWeatherMap API

## Prerequisites
- **Backend**:
  - PHP >= 8.1
  - Composer
  - Laravel 10.x
  - An OpenWeatherMap API key
- **Frontend**:
  - Node.js >= 18.x
  - npm or Yarn
